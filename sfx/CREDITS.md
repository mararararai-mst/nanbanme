# 効果音の出典

音源：効果音ラボ（https://soundeffect-lab.info/）
利用規約：https://soundeffect-lab.info/agreement/
（アプリの操作音としての組み込みは可・クレジット不要・加工可。素材そのものの再配布、直リンクは禁止）

| ファイル | 元の素材 | 加工 |
|---|---|---|
| se_correct.mp3 | クイズ正解2（anime/correct2.mp3） | 前後の無音を切り、音量調整・フェードアウト |
| se_wrong.mp3 | クイズ不正解1（anime/incorrect1.mp3） | 音量調整 |
| se_clear.mp3 | ラッパのファンファーレ（anime/trumpet1.mp3） | 後ろを切り、音量調整・フェードアウト |
| se_pick.mp3 | パッ（anime/pa1.mp3） | 後ろの無音を切り、音量調整 |
| se_drop.mp3 | ペタッ（anime/peta1.mp3） | 後ろの無音を切り、音量調整 |

※ 素材単体での配布・転載はしないこと。アプリに同梱して操作音として使う。
